# 真实账号验收（需要用户操作）

当前离线与界面测试使用合成账号，没有执行以下真实账号操作。无需把 Token、授权码或带凭据的链接发给开发者。

1. 保存 Devin Desktop 中的工作。准备两个本人有权使用的账号 A、B。
2. 在管理器通过网页授权添加 A、B；确认浏览器返回后账号确实保存。记录是回调、凭据处理还是保存阶段报错。
3. 分别刷新 A、B，核对套餐、额度与更新时间。额度异常不等同于凭据失效。
4. 切换 A → B → A，每次在官方客户端核对账号与组织，并进行一次正常、获授权的服务请求；管理器的“当前”标识仅证明本地匹配。
5. 重启管理器，确认两账号和最近切换记录保留。
6. 设置 → 数据管理：确认存在加密恢复点。需要验证恢复时，先保存工作，再恢复上次状态，核对官方客户端账号。此操作覆盖切换后的客户端数据库状态。
7. 对存在未保存工作或退出确认窗口的客户端发起切换，应提示正常关闭；未退出时应中止，不能强制终止进程。
8. 迁移 Cockpit 时，核对导入/跳过/失败数量；同邮箱不同组织应独立保留。组织切换后的凭据需由官方流程实际确认。

不通过制造真实网络故障、篡改真实数据库或删除密钥验证恢复；这些故障已在隔离临时数据库中测试。真实异常恢复应仅在可控测试配置中进行。
