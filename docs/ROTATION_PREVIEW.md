# 额度轮换客户试用版

本预览版基于 v0.4.0，提供额度监控、候选账号推荐、用户确认及轮换状态恢复保护。安装后的应用版本号仍显示 0.4.0；请通过 Release 标题区分本预览包。

## 使用说明

1. 在应用设置的「额度轮换」中选择监控模式、阈值和备用账号，保存设置。
2. 「立即扫描」查询真实额度；只有满足门禁并经过重复低额度确认时，才产生切换建议。没有建议不等于扫描失败。
3. 推荐横幅中的确认操作使用实验性官方 URI 登录，需要在 Devin Desktop 中完成官方确认。普通账号卡片的切换仍使用原有标准流程，可能重启 IDE。
4. 切换后检查官方客户端账号，并实际发送一次 AI 请求。退出官方账号后重新网页登录，也是试用验收的一部分。

## 已知限制

- 官方 URI 免重启切换尚未完成真实客户端验收，不能保证窗口、运行中的 AI 任务或后续请求无中断。
- 全自动模式未开放；当前提供监控提醒和用户确认。
- 暂无独立的手动「免重启切换」入口，实验性入口随低额度推荐出现。
- 本地会话没有组织字段；本地验证不能证明组织和计费归属，身份歧义时应等待人工核对。
- 备用账号池布局、扫描反馈和功能入口仍需完善。

113 项离线 Rust 测试、前端构建和模拟界面检查不能替代真实账号验收。试用时请先保存 IDE 工作，仅使用有权管理的账号；不要在反馈中附带 Token、Cookie 或完整登录数据库。

实现、审核记录及真实验收步骤见 [REVIEW_HANDOFF.md](REVIEW_HANDOFF.md) 和 [ROTATION_VALIDATION.md](ROTATION_VALIDATION.md)。
