# 额度轮换客户试用版

本预览版基于 v0.4.0，提供额度监控、候选账号推荐、用户确认、手动免重启切换入口及轮换状态恢复保护。安装后的应用版本号仍显示 0.4.0；请通过 Release 标题区分本预览包。

## 使用说明

1. 在应用设置的「额度轮换」中选择监控模式、阈值和备用账号，保存设置。页面顶部会显示监控状态、已保存备用账号数和上次扫描时间。
2. 「立即扫描」按已保存设置查询真实额度（有未保存修改时会标注）；只有满足门禁并经过重复低额度确认时，才产生切换建议。没有建议时会显示本次未推荐的原因，不等于扫描失败。
3. 切号方式可在应用设置「客户端 → 切号方式」选择，默认标准切号：
   - 标准切号（重启，默认）：卡片主按钮「切换账号」走保存后重启客户端的标准流程，请先保存工作。
   - 尝试免重启（实验性）：卡片主按钮变为「免重启切换」，走官方 URI 登录流程；发起后 Devin Desktop 可能弹出官方确认框，需在 Devin 中确认；随后点「验证生效」检查登录账号。**URI 发出不代表切换成功。**「标准切号」仍保留为次要按钮。
   - 缺少官方 URI 登录所需凭据的账号会标注「暂不支持免重启」，仍可标准切号。凭据就绪的条件是账号持有 Devin 会话令牌（网页授权、本机导入或 `devin-session-token$` 粘贴导入都会保存它）或可用的 `ott$`/`oidc$` 令牌；发起时服务端铸造一次性登录令牌，若账号仅有会话令牌而官方接口要求更多上下文，会以铸造失败如实报错。纯旧版（sk-ws/Firebase）凭据、无会话令牌的账号仍标注不可用。「添加账号 → 邮箱密码」或 `auth1_` token 导入会补齐完整会话字段，铸造成功率最高。
4. 切换后检查官方客户端账号，并实际发送一次 AI 请求确认身份。退出官方账号后重新网页登录，也是试用验收的一部分。

## 已知限制

- 官方 URI 免重启切换尚未完成真实客户端验收，不能保证窗口、运行中的 AI 任务或后续请求无中断。
- 全自动模式未开放；当前提供监控提醒和用户确认。
- 本地会话没有组织字段；本地验证不能证明组织和计费归属，身份歧义时会显示待核对而非已生效。
- 免重启 URI 发起时，登录令牌会短暂出现在系统进程命令行中。

116 项离线 Rust 测试、前端构建和模拟界面检查不能替代真实账号验收。试用时请先保存 IDE 工作，仅使用有权管理的账号；不要在反馈中附带 Token、Cookie 或完整登录数据库。

实现、审核记录及真实验收步骤见 [REVIEW_HANDOFF.md](REVIEW_HANDOFF.md) 和 [ROTATION_VALIDATION.md](ROTATION_VALIDATION.md)。
