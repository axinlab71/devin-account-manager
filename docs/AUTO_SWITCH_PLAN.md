## A. 已锁定决策与公共约定

### 用户选择与边界

- 从接手时确认的最新 main 新建 `feat/safe-account-rotation`，不改稳定分支，不重写正常登录/导入/额度/切号协议。
- 先离线实现与合成测试；真实 Windows 隔离环境尚未提供。不能用用户默认 profile 做破坏性实验。
- 首版仅管理器运行时监控，退出即停止；阶段六托盘延后，不是首批发布条件。
- 允许跨组织推荐，但仅从用户主动启用的备用池选择；确认显示组织差异；跨组织全自动禁用。
- 智能确认是默认模式；首次安装监控关闭。全自动只在精确版本的 L2、认证兼容、任务/编辑安全状态全部验收通过后启用。
- L1=标准免重复登录但需重启；L2=同 PID/窗口、官方身份及后续请求切换；L3=运行任务跨账号继续，本计划不实现、不宣传。
- 不改官方目录/密钥/服务名/协议/安装文件，不生成设备标识、不跳过验证。查询/排序不修改官方登录状态；无用户明确允许不得注销或重启。保留 `account_view`、`auth_endpoint`、`client_recovery`、现有锁及安全存储。

### 计划默认值（尚未实现）

| 项 | 默认 / 规则 |
| --- | --- |
| 阈值 | 10%，可配 0～30%；任一适用限制剩余 ≤ 阈值即低额度；0% 阈值只在耗尽时触发 |
| 轮询 | 60 秒，可配 30～3600 秒；单次请求有界，串行查询，禁止重叠扫描 |
| 新鲜度/确认 | 查询成功时间距现在 ≤120 秒；低额度两次独立成功查询、间隔至少 5 秒；来源/套餐语义必须验证 |
| 候选余量 | 每项适用限制均高于阈值至少 5 个百分点；未知/不适用不能补成 0 |
| 全局间隔 | 执行切换间隔至少 10 分钟；执行时再次检查，不仅限制推荐 |
| 冷却 | 切出账号默认 30 分钟；限流遵循可信 Retry-After；耗尽账号到相关重置后重新查询再解禁 |
| 熔断 | 连续执行失败 3 次暂停，用户查看原因后显式恢复；读失败单独退避，不计作已尝试切号 |
| 排序 | 默认最小适用剩余比例降序，再用户优先级降序、最近重置升序、最近切换升序、ID；未知重置排后、无切换记录视为最久未切换 |
| 其他排序 | 优先级优先/最早重置优先/最久未切换优先作为主键，余下按默认顺序打破平局 |
| 重启恢复 | 只恢复配置和冷却记录，不执行旧建议；重新读取当前身份和查询。时钟异常、过期、身份歧义均停止执行 |

阈值 0、候选安全余量和窗口边界都需测试。参考默认值是计划决策，不是服务端保证；不得把 OMP API 路由行为当作 IDE 兼容性证据。

### 拟新增接口与文件（都尚不存在）

- Rust：`src-tauri/src/modules/quota_monitor.rs`、`rotation_policy.rs`、`account_selector.rs`、`switch_adapter.rs`、`rotation_state.rs`；只在 `modules/mod.rs` 和 `lib.rs` 做必要注册/编排。
- `QuotaSnapshot`：内部账号 ID、Devin Account ID/Org ID、计费类型、限制列表（daily/weekly/prompt/flow/flex）、适用性、remaining/total/percent、重置时间、查询时间、语义依据和健康状态。无 Token；未知值用 Option/枚举，不补零。
- `RotationDecision`：no-action / warning / recommendation / blocked、结构化原因、候选摘要、快照版本；不能自带客户端写权限。
- `SwitchRequest`：目标账号 ID、预期当前账号/组织、建议 ID、明确确认及允许的方式；后端不把任意前端布尔值当全自动资格证据。
- `SwitchResult`：目标账号、实际方法、是否需要/发生重启、本地匹配、客户端识别、官方远端验证、回滚状态和失败码。验证状态用 not-attempted/passed/failed/unknown；rollback 用 not-needed/attempted/succeeded/failed，避免含混布尔值。
- `RotationState`：schemaVersion、配置、启用池、优先级、冷却、最近切换、失败计数和暂停原因。用本工具数据目录的 `rotation-state.json` 原子保存；无凭据，不修改已有账号详情格式。
- 计划 Tauri IPC：`get_rotation_status`、`set_rotation_config`、`scan_rotation_now`、`pause_rotation`、`resume_rotation`、`confirm_rotation`、`get_switch_capabilities`；只返回安全 DTO。状态事件以 `rotation-status` 更新 UI，后端拥有轮询任务。
- React 新组件：`src/components/RotationSettings.tsx`、`RotationRecommendation.tsx`，必要服务包装独立文件；不把业务规则堆到 `main.tsx`。沿用现有 Modal 的焦点/取消保护及卡片布局。
