# 验证与测试规范记录

## 0.2.0 当前变更（2026-10-15）

- **额度解析与数据提取**：全面复用成熟的额度解析与数据提取模块，与 Rust protobuf field 14/15 剩余比例语义严密对齐；缺失数据明确区分，不虚构为已耗尽或零余额。
- **额度全场景测试**：`node scripts/test-quota.cjs` 自动化测试全量通过，覆盖 camel/snake 兼容、零额度与缺失区分、额度方向、重置时间戳、Credits 总量/已用/剩余、边界截断及二进制 protobuf 快照解码。
- **本地只读诊断验证**：使用只读 probe 检查本地存储结构，确认真实缓存包含日/周限额及重置字段，绝无任何凭据导出、明文打印或网络泄露。
- **核心后端回归测试**：32 项 Rust 后端离线回归测试 100% 通过（涵盖安全加密、DPAPI 保护、原子写入与回滚、直连 Fallback 机制等）。
- **界面与交互验收**：合成数据集验证通过，包括日/周限额柱状图、Credits 余额、客户端设置弹窗、4.5 秒自动关闭提示、搜索/筛选/导入/删除/深浅色主题。
- **品牌规范与兼容性**：产品名与窗口标题更新为 **Devin Account Manager**，底层存储与旧版完全无缝兼容。

## 0.1.5 网络传输层优化

- 针对代理环境偶发的 TLS 握手异常，接入统一的容灾传输层：默认先走系统/环境代理；仅在连接建立失败且请求可克隆时，安全降级尝试一次直连，全程保留证书与域名校验，绝不修改系统全局代理。
- 32 项后端回归测试通过，覆盖坏代理直连回退、Payload/UA 完整保留、状态码精确处理等场景。

## 0.1.1 客户端协同与本地导入

- 建立官方客户端 SQLite 状态识别与只读会话解密机制。
- 引入切号前自动热备份数据库与事务回滚保护。

## 安全架构与非侵入式设计

1. **凭据安全**：所有账号凭据在本地均采用 AES-256-GCM 工业级加密存储，并在 Windows 系统下结合用户专属 DPAPI 深度保护。
2. **非侵入式**：应用严格遵循安全设计，仅在用户主动点击“切换”时才对客户端数据库执行带备份的事务写入，绝不暗中操作用户工作环境。
3. **隐私脱敏**：任何诊断日志、测试套件与开源代码均执行严格审查，不含任何私人 Token、会话凭据或工作文件。
